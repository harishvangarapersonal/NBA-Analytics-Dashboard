# NBA Analytics Dashboard using Power BI

## Project Overview

This project was developed as part of the **Statistella: Data Analytics Competition** organized by the **Indian Institute of Technology (IIT) Banaras Hindu University (BHU)**.

The dashboard provides an interactive analysis of NBA teams, players, scoring trends, conference performance, and game statistics using Power BI and DAX.

The objective of this project is to transform raw NBA datasets into meaningful visual insights and analytical storytelling for sports performance evaluation.
